# Tree Huggers
Starter page for our CS6730 final project.
Group members: Aidan Murray, Weisheng Zhang, Christian Cardenas, Yanni Xu, Sophia Hawkins

## Preview the page

Clone this repository and open this folder in your local IDE. Run `python3 -m http.server 8000` in this folder and open `http://localhost:8000`.

## Folders

- `index.html` — the page.
- `css/` — how the page looks.
- `js/` — the chart code.
- `data/` — the data the charts read.
- `assets/` — images and icons.

Team data: [Tree and Heat Drive folder](https://drive.google.com/drive/folders/1uCAo0cepBbM2_c6U0dncRwvs6m73PpnP).
